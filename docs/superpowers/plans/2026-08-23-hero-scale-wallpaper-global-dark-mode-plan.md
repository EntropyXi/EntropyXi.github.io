## 2. 详细执行步骤

### 步骤 1：重构 `AmbientBackground.astro` 全站通用壁纸与磨砂层

- 移除 `isHome &&` 条件，使所有页面共享固定的水仙夕阳高清壁纸；
- 保留全站平滑 Scrim，保证无论滚动到何处，壁纸始终固定在视口底层。

### 步骤 2：优化 `PostLayout.astro` 与 `prose.css` 文章页玻璃质感

- 为 `.post-main` 与 `.post-sidebar` 配置高级深色磨砂玻璃（`rgba(10, 12, 22, 0.72)` + `backdrop-filter: blur(16px)` + 细腻边框）；
- 消除原先沉闷的死黑块，使文章主体悬浮于水仙夕阳壁纸之上。

### 步骤 3：重构 `Hero.astro` 首屏超大标题与左下锚定比例（对齐 002433）

- 标题字号：`clamp(3.6rem, 6.2vw, 6.5rem)`；
- 叙述文案间距：`margin-top: clamp(6rem, 14vh, 12rem);`，形成左上超大标题 + 左下精致说明的双重平衡；
- 增加科技感折角底边（`border-bottom` + 拐角发光指示）。

### 步骤 4：移除日夜切换，全站永久锁定夜间模式

- `src/components/chrome/SiteHeader.astro`：移除 `<ThemeToggle />`；
- `src/layouts/BaseLayout.astro`：固化 `data-theme="dark"`；
- `src/lib/client/theme.ts`：固化为 dark 单一主题；
- `src/styles/tokens.css`：删除 `[data-theme="light"]` 规则块。

### 步骤 5：更新测试套件与执行 9 步质量门禁

- 更新 `client-behavior.spec.ts`、`hero-contrast.spec.ts`、`client-foundation.test.ts`；
- 执行 `npm run check` 确保 100% 通过；
- Git Bash 提交并推送到 `main` 与 `source`，验证 GitHub Actions 部署。
