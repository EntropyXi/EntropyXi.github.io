# ADR 0002：文章图片暂不引入灯箱

- 状态：已接受
- 日期：2026-08-20
- 关联计划：`docs/superpowers/plans/2026-08-20-astro-migration-plan.md` §8.3 / §11

## 背景

迁移范围内已发布图片仅 `images/eigenvalue-error.png` 一张，且当前文章
图片引用已全部有对应资源。阶段 3 要求评估灯箱的必要性。

## 决策

文章页暂不引入图片灯箱。当前图片数量少、尺寸可控；浏览器原生打开
图片链接即可满足查看原图需求，不增加额外 JavaScript。

## 后续条件

如果阶段 5 视觉改版后文章图片数量明显增加，或出现需要放大的技术图，
再以独立 ADR 评估灯箱方案。无 JavaScript 降级始终保留：即使未来引入
灯箱，`<a href="原图">` 仍必须可用。
