# 阶段 0 视觉矩阵

## 固定页面

| ID             | 路径                                          | 目的                         |
| -------------- | --------------------------------------------- | ---------------------------- |
| `home`         | `/`                                           | Hero、文章流、分页入口       |
| `article-ddim` | `/2026/05/10/深度学习/流匹配与扩散模型/DDIM/` | 长文章、目录、公式、移动阅读 |
| `archives`     | `/archives/`                                  | 聚合与时间信息               |
| `categories`   | `/categories/`                                | 分类聚合                     |
| `tags`         | `/tags/`                                      | 标签聚合                     |
| `search`       | `/search/`                                    | Pagefind 交互入口            |
| `about`        | `/about/`                                     | 普通内容页                   |
| `404`          | `/404.html`                                   | 错误状态与恢复导航           |

每个页面固定采集：

- 1440×900 dark；
- 1440×900 light；
- 390×844 dark；
- 390×844 light。

文件命名：`{id}-{viewport}-{theme}.png`。

## 使用规则

- 阶段 0 图片只用于证明重构前的内容层级、可读性和响应式事实；
- 不把当前像素布局当成新设计必须维持的目标；
- 阶段 1 以后每阶段放到自己的 `phase-N/`，不覆盖阶段 0；
- 动态效果截图必须冻结动画；
- 最终差异必须同时通过 DOM、键盘、axe、性能和路由测试，不能只看图片。
