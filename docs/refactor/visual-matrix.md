# 阶段 0 视觉矩阵

## 固定页面

| ID             | 路径                                          | 目的                         |
| -------------- | --------------------------------------------- | ---------------------------- |
| `home`         | `/`                                           | Hero、文章流、分页入口       |
| `article-ddim` | `/2026/05/10/深度学习/流匹配与扩散模型/DDIM/` | 长文章、目录、公式、移动阅读 |
| `archives`     | `/archives/`                                  | 聚合与时间信息               |

每个页面固定采集：

- 1440×900 dark；
- 1440×900 light；
- 390×844 dark；
- 390×844 light。

文件命名：`{id}-{viewport}-{theme}.png`。

> 主题说明：站点自 2026-08-23 起永久锁定暗色主题，亮色组合不再新增采集；
> 历史基线中的 light 截图仅作阶段证据保留。

## 使用规则

- 阶段 0 图片只用于证明重构前的内容层级、可读性和响应式事实；
- 不把当前像素布局当成新设计必须维持的目标；
- 阶段 1 以后每阶段放到自己的 `phase-N/`，不覆盖阶段 0；
- 动态效果截图必须冻结动画；
- 最终差异必须同时通过 DOM、键盘、axe、性能和路由测试，不能只看图片。

## 阶段 3 全局外壳证据

证据索引：`audit-screenshots/phase-3/index.json`。

| ID                         | 视口     | 主题  | 动态偏好 | 验收重点                                    |
| -------------------------- | -------- | ----- | -------- | ------------------------------------------- |
| `home-dark-desktop-1440`   | 1440×900 | dark  | full     | 四层背景、展开页头、暗色对比                |
| `home-light-desktop-1440`  | 1440×900 | light | full     | 浅色令牌、次要文字对比、低密度背景          |

索引中的每个案例都记录主题终态、视口宽度、页面滚动宽度、页头状态、环境层显示状态、动画名、指针行为和堆叠层级。截图冻结动画只用于稳定取证；低动态停止循环同时由运行时计算样式和 Playwright 项目验证。

补充人工验收：Chrome 151 在本地静态预览中确认桌面暗/亮主题、移动抽屉与页面宽度正常；`Context Recall` 复杂公式文章实测包含 20 个 `mjx-container`，首个显示公式为块级、可见且未造成页面级横向溢出。公式完整性仍以产物审计的 1,289/1,289 条可访问公式为全量证据。
