Rust 是一种静态类型语言。

## 整数

![表 3-1：Rust 中的整数类型，按长度列出 8 位到 128 位以及取决于架构的 isize 与 usize，并给出对应的有符号与无符号写法](/images/rust/rust-integer-types.png)

如果发生溢出，在调试模式编译时，Rust 会自动进行整数溢出检查。如果发生这种行为，会导致你的程序在运行时 _panic_。当程序因错误而退出时，Rust 使用术语 _panicking_。

手动处理溢出的话，可以使用以下方法：

- 使用 `wrapping_*` 方法在所有模式下回绕，例如 `wrapping_add`
- 使用 `checked_*` 方法在发生溢出时返回 `None` 值
- 使用 `overflowing_*` 方法返回值以及一个表示是否发生溢出的布尔值
- 使用 `saturating_*` 方法在值的最小值或最大值处饱和方法

## 浮点数

`f32` 和 `f64`：

```rust
let x = 2.0; // 默认为 f64
let y: f32 = 3.0; // 指定声明为 f32
```

## 数值计算

整数除法会向零截断到最接近的整数。

## 元组

元组中可以包含不同类型，但长度不能更改：

```rust
fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);
}
```

要从元组中获取各个值，我们可以使用模式匹配来解构元组值：

```rust
fn main() {
    let tup = (500, 6.4, 1);
    let (x, y, z) = tup;
    println!("The value of y is: {y}");
}
```

这个程序首先创建一个元组并将其绑定到变量 `tup`。然后它使用带有 `let` 的模式，将 `tup` 转换为三个独立的变量：`x`、`y` 和 `z`。这被称为_解构_，因为它将单个元组拆分为三个部分。最后，程序打印 `y` 的值，即 `6.4`。

我们还可以通过使用句点（`.`）后跟要访问的值的索引来直接访问元组元素：

```rust
fn main() {
    let x: (i32, f64, u8) = (500, 6.4, 1);
    let five_hundred = x.0;
    let six_point_four = x.1;
    let one = x.2;
}
```

没有任何值的元组有一个特殊的名字：单元。这个值和它对应的类型都写作 `()`，表示空值或空的返回类型。如果表达式不返回任何其他值，就会隐式返回单元值。

## 数组

数组的每个元素都必须具有相同的类型，且具有固定长度：

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    let a: [i32; 5] = [1, 2, 3, 4, 5];
}
```

也可以通过指定初始值，后跟分号，再在方括号中指定数组长度，来初始化一个每个元素都包含相同值的数组：

```rust
let a = [3; 5]; // let a = [3, 3, 3, 3, 3]
```
